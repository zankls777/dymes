# BOM3 大焱资料管理系统 — 使用说明

> 访问地址：`http://localhost:5004`　|　搭建步骤见 [SETUP.md](SETUP.md)

---

## 1. 登录与界面基础

- 使用管理员分配的账号登录；首次部署默认 `admin / admin123!`，**请立即修改**。
- 系统采用**多标签页**设计：点击菜单在新标签打开页面；在标签页按 F5 刷新会自动关闭当前标签并跳到相邻标签（首页刷新不关闭）。
- 左侧菜单按权限显示，无权限的菜单项自动隐藏；直接输入无权限页面的地址会被拦截并提示。

## 2. 文件管理

### 2.1 文件上传
- 上传 SubList / UsageList（.xlsx/.xls），支持查看、下载、删除。
- **冻结/解冻**（需 `can_file_management_freeze` 权限）：
  - 同一品番出现新版 EO 时，旧 EO 数据**自动冻结**；冻结的文件及其 SubList/UsageList 数据禁止一切调用。
  - 需要使用冻结数据时，手动点击「解冻」按钮。
  - 支持单个与批量冻结/解冻，以及「一键冻结旧版本」预览后执行。

### 2.2 文件对比
- 支持单文件/多文件对比，输出差异明细并可导出。

### 2.3 NAS 文件搜索 / 文件类型查询
- NAS 文件搜索：检索共享盘中的资料文件。
- SubList / UsageList：按品番等条件查询已入库数据。

## 3. 成品管理与车种管理

- **成品管理**：维护品番主数据。
- **车种管理**：维护车种（车型）基础信息。

### 3.1 成品 EO 与资材量计算规则

#### EO 字段来源

- **成品实际 EO**：保存于 `finished_product.eo`，来源于手动添加、批量添加或 Excel 导入及冲突处理后保存的成品 EO。
- **UsageList 参考 EO**：保存于 `finished_product.usage_eo`，用于录入冲突判断和页面展示，不等同于成品实际 EO。
- **LOT 登录 EO**：保存于 `lot_login_info.jx_eo`，属于 LOT 登录资料，不作为资材量计算的 EO 来源。
- 成品列表优先显示实际 EO；实际 EO 为空时才回退显示参考 EO。此显示规则不代表计算规则：资材量计算只处理实际 EO 非空的成品，实际 EO 为空的记录不参与计算。

#### 资材量计算时的 EO 选择顺序

1. 读取成品实际 EO，并对品番和 EO 做规范化：品番忽略大小写、空格及不同横线字符，EO 去除首尾空格并统一大写。
2. 按“成品品番 + 成品实际 EO”精确匹配 UsageList。匹配成功时使用成品实际 EO，即使该品番已经存在更新版本，也不会自动切换。
3. 精确匹配失败时，回退到该品番在 UsageList 中的最新 EO。标准 EO 按字母和数字版本比较，例如 `e9 > e8 > d9`。
4. 最新 EO 按品番统一选择，不按车种或 LOT 分别选择；候选数据排除已删除记录，但包含冻结版本。
5. 如果 UsageList 中没有任何可用于该品番的 EO，该成品无法匹配 UsageList，不生成相应的资材用量结果。

#### 与 LOT 登录 EO 不一致提醒的关系

- 成品添加或批量添加时，系统按相同 LOT 号比较成品实际 EO 与 LOT 登录 EO。
- 两者不一致时仅弹出提醒，不会自动修改成品 EO，也不会将 LOT 登录 EO 用于资材量计算。
- 如果计算结果中的 EO 与 LOT 登录 EO 相同，可能是两者本身登记一致，或最新 EO 回退后恰好一致，不代表计算读取了 LOT 登录 EO。

示例：某成品实际 EO 为 `e8`，UsageList 同时存在 `e8` 和 `e9` 时，计算使用 `e8`；如果 `e8` 已不存在，则回退使用最新的 `e9`。

相关实现入口：资材量计算 `update_material_summary`，LOT EO 不一致检查 `_check_lot_eo_mismatch`。

## 6. 波纹管位置

- **波纹管位置登录**：维护波纹管位置数据（上传模板、编辑、清空、自定义列）。
- **波纹管位置查询**：免登录查询页，供现场直接检索。

## 7. RW 图纸业务

- **RW 核对**：上传差异表生成核对清单，支持手动补录、清单下载、明细 ZIP 打包下载。
- **RW 图纸产出**：上传 DXF 图纸 + 差异表，自动在图纸中标记目标回路（RW_MARK），产出标记后的 DXF 供下载。

## 8. 线束业务（LOT 登录 / 扫描录入 / 数据下载）

### 8.1 LOT 登录
- 打开页面为**按钮弹窗模式**：「手动登录」或「Excel 批量导入」。
- **品番 + 京信 EO 为必填项**（组合不存在时红字提示并展示无资料清单卡片）。
- LOT 号规则：`LOT + 两位数 + 回路号`（LOT 后必须跟两位数字）。
- 同一 LOT 下允许录入重复号机。
- 登录成功后显示最大化结果层，可下载 Excel、返回或继续操作。
- 列表页为服务端分页（默认 200 条/页），支持搜索与「仅看无资料」过滤，可导出 Excel。

### 8.2 扫描录入
- **回路扫码**：扫 LOT 条码后按 `LOT+两位数+回路号` 录入；**号机扫码**：格式 `M-xx$编号`（如 `M-08$2`）。
- **补线数量必须大于 0**，输入 0 前后端均拦截无法保存；数量为 0 的待保存行红色高亮。
- **拍照识别**：上传线束标签照片，本地 OCR 自动识别图纸管理编号、回路号、端子、压高、LOT、品番等字段并回写：
  - 识别不到压高时，自动取同图纸管理编号 + 同端子对的历史压高回写（不新增错误记录）。
  - 同图纸任意回路扫码固化时，自动按 SetCode 批量匹配压高知识库；端子对不匹配则保留原值。
- **数据修改**：支持逐字段修改（LOT/回路/号机/数量）；号机显示为 `M-xx`，但保存使用完整原值（`$` 后缀不丢失）。

### 8.3 数据下载
- 打开即自动加载最近 3 天数据，支持修改与删除（删除有二次确认）。

## 11. 系统管理

- **用户与权限管理**：用户增删改、导入模板批量导入、批量分配权限组。
- **权限管理**：按页面/按钮粒度配置权限（如冻结权限 `can_file_management_freeze`）。
- **权限组**：角色组管理，组权限 + 用户个性化覆盖，可查看用户最终生效权限。
- **数据备份管理**（仅管理员）：
  - 手动备份/恢复、备份进度查询、按表导出。
  - **自动备份到网盘**：配置目标目录（支持 UNC 网络路径）、模式（全量/增量/两者）、每日全量时刻、增量间隔与保留份数，后台每分钟自动调度。
- **菜单管理**：调整菜单项。
- **操作记录**：全站操作日志审计。
- **开发人员信息设置**：维护开发信息展示。

## 12. 常用业务规则速查

| 规则 | 说明 |
|------|------|
| EO 版本顺序 | a1→a9、b1→b9、c1→… 依次递进，新版 EO 出现即冻结旧版 |
| 冻结数据 | 文件与其 SubList/UsageList 同步冻结，禁止任何调用；解冻后方可使用 |
| LOT 号 | LOT 后必须跟两位数字 + 回路号 |
| 号机 | 允许重复录入；显示 `M-xx`，存储完整 `M-xx$编号` |
| 补线数量 | 必须 > 0 |
| 压高知识库 | 唯一键 = 图纸管理编号 + 端子对；识别不到时回写历史压高快照 |
| 时间显示 | 全站统一 UTC+8 |

## 13. 常见问题（使用类）

| 现象 | 处理 |
|------|------|
| 页面菜单不全 | 联系管理员在「权限管理/权限组」中开通对应权限 |
| 文件不能下载/调用 | 文件可能已被冻结（EO 旧版），在文件上传页解冻后使用 |
| 拍照识别不准 | 确认照片清晰、标签正放；OCR 引擎升级后识别率可能有小幅波动，持续偏差请提供原始照片给管理员调参 |
| 扫码后提示品番无资料 | 该品番+EO 组合未上传资料，先在「文件上传」完成上传 |
| 导出 Excel 较慢 | 大数据量导出已流式优化；仍慢时缩小筛选范围分批导出 |
