============================================================
 BOM3 大焱资料管理系统 - 快速开始
============================================================

一、环境要求
  - Python 3.10+（推荐 3.12；Win7 只能作为浏览器访问端）
  - 可离线运行；标签拍照识别需安装 OCR 四件套（见 docs/SETUP.md 4.4）

二、首次安装（Linux / NAS）
  python3.12 -m venv .venv
  .venv/bin/pip install -r requirements.txt
  .venv/bin/pip install zxing-cpp rapidocr-onnxruntime opencv-python-headless Pillow
  chmod +x start.sh
  bash start.sh                  # 默认 5004 端口
  # 指定端口：bash start.sh --port 8080

三、Windows
  双击 start.bat（自动检查依赖、清理端口、生产模式启动并打开浏览器）

四、访问与登录
  地址：http://<服务器IP>:5004
  账号：admin
  密码：设置了环境变量 ADMIN_PASSWORD 时以其为准；
        否则查看 instance/admin_initial_password.txt
  首次登录后请立即在“用户管理”修改密码。

五、常用命令
  ps -ef | grep "app.py"         # 查看进程
  kill -9 <PID>                  # 停止服务
  bash start.sh                  # 重新启动（自动清理端口占用）

六、在线更新（可选）
  1. 管理员登录“关于”页 → “检查更新” → “更新并重启”
  2. 无法访问 GitHub 时，在“网络与加速设置”配置代理或加速源（如 https://gh-proxy.com/）
  3. 服务器未安装 git 时执行：./.venv/bin/python -m pip install dulwich
  4. 更新与重启日志：logs/update_restart.log

七、文档

八、数据安全
  - instance/app.db 为数据库，static/uploads/ 为上传文件，请定期备份
  - 在线更新保留 instance/、logs/、backups/、.venv/，覆盖前自动备份到 backups/
  - .secret_key（会话密钥）与 instance/ 不应提交到代码仓库
